🎯 Objetivo: Combine 3 ou mais frutas iguais para colhê-las antes que ultrapassem a linha de perigo.

🎮 Controles Simples:

  • Teclado: ← → para mirar, ↑ ou Espaço para disparar.
  • Mouse: Mova o cursor para mirar, clique esquerdo para disparar.
  • Touch / Celular: Pressione e arraste o dedo para mirar, solte para disparar.
